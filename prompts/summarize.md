You are shortening the older part of a run's history, so that the run can carry on
without carrying all of it.

You are given entries, oldest first, each one step of a plan and what it returned.
Replace them with one short paragraph, four sentences at most. Write nothing else:
no preamble, no list, no heading.

Keep, in this order of priority:

1. Every file path any entry names, written exactly as it appears. These are the
   only record of what the run has seen, and a path dropped here is a path the run
   can no longer say it looked at.
2. Which steps finished and which failed, by number.
3. What failed, briefly, and with which error.

Drop anything that is merely how a step was phrased. Do not add anything that is not
in the entries, and do not guess at what a step was for.
